# 慢慢看 · 合规红线

> 开发者贡献代码时，所有用户可见输出必须过本文件的红线检查。

---

## 1. 红线（不得触碰）

- 推荐具体股票买卖
- 预测涨跌 / 给出目标价
- 给出"建议买入 / 卖出"标签
- 提供"AI 选股建议"并收费
- 文案出现以下关键词

## 2. 安全区

- 展示客观行情数据（OHLCV）
- 展示用户自定义的筛选结果
- 提供技术指标计算工具
- 用户自行设置的价格预警
- 措辞："60 日最低 / 触及 30 日低点 / 价格位于 90 日区间下沿"

## 3. 关键词黑名单

以下词汇**不得出现在任何用户可见输出中**：

```
低估, 被低估, 值得买入, 建议关注, 目标价, 底部, 见底,
建议买入, 建议卖出, 推荐, 看好, 看空, 抄底, 逃顶,
必涨, 必跌, 稳赚, 包赚, 保本
```

## 4. 命名约定

- **品牌名**：慢慢看（避开"买"字，不暗示行为）
- **目录名**：`manmankan`（拼音）

## 5. 强制文案

每次 CLI 输出底部 / 每个 Web 页面 footer 必带：

> **创新低 ≠ 见底 · 创新高 ≠ 顶 · 历史价格不预示未来 · 仅供参考，不构成投资建议**

## 6. 合规定位

本工具严格定位为**行情数据展示工具**，不包含买卖建议、评分评级、策略推荐等任何投资指导性质的功能。使用延时行情数据（盘后批量拉取）。
