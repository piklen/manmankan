# 产品方向

慢慢看围绕**从数据中发现并理解市场变化**迭代。衡量标准是用户能否说清一个现象、辨认其分母和边界，并追到成员证据；不以指标、图表、测试或入口数量衡量进展。

## 当前产品

- 完整范围的涨跌分布、中位数、分位与缺口；无需先定义股票筛选条件。
- 行业剖面、两个相邻等长窗口的参与变化与方向迁移；每个统计可下钻同一批成员。
- 固定成员的滚动窗口轨迹，区分当前完整、两段可比与轨迹完整三种分母。
- 保存完整成员的观察事实与自己的想法，显式复看同一批成员；原记录保留，未知单列。
- 成员日线证据与明确条件研究；连续段、波段、多周期位置、形态参照和历史事件共用计算。
- 本机 Web/终端/CLI/Python/MCP 共享事实，SQLite/Parquet 保存个人资料与明确执行的研究。

## 后续取舍

先验证真实用户是否能发现并复述变化，再决定增加哪种数据。新增资料必须补足当前认识盲点，并能解释时间、来源和缺口；没有证据时不把相关性写成因果。

不以增加默认策略、综合评分、推荐排名或自动生成结论代替产品价值。不重复建设交易执行、云账户、策略训练或独立数据服务平台。新抽象、缓存与任务体系要有当前瓶颈证据。

不做历史行为兼容；删除旧实现同时保护用户数据和恢复路径。代码交付与正式 PyPI/GitHub Release 分开，公开发布依明确授权。
