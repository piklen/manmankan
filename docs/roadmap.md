# 产品方向

慢慢看围绕 **趋势搜索与定位** 集中迭代。衡量标准是用户能否更快发现变化、看清多周期位置，并将观察变成可核对的研究；不以入口、指标、测试或模块数量衡量进展。

## 当前交付

- 直接表达连续涨跌、阴阳线、前后连续段和区间涨跌次数；叠加位置、区间变化与明确行业范围。
- 当前表格与地图共用匹配集合，逐股日线、连续段起点、本段变化与多周期位置可核对；框选回填明确条件。
- 实际走势的形态距离检索，完整窗口与参照事实可追溯。
- 当前筛选不创建研究，命名保存只保存条件；历史需确认窗口后执行并留存，支持冻结证据与显式最新重跑。
- Web、TUI 都能直接填条件；CLI `kan trend` 和 MCP `kan_trend` 使用同一查询，`kan study` 负责历史。
- 清理旧 HTTP 栈、重复任务、历史测试兼容和无实际收益的门禁。

## 后续选择依据

先依据真实使用中无法表达或无法核实的问题增加能力。分钟事件需要实际可用且覆盖清楚的数据，不以部分样本冒充全池概率；板块、事件或其他资料也必须服务于同一发现与验证主线。

保持个人研究工具定位，不重复建设公司基本面比较、交易账本、交易执行、云账户与策略训练平台。不做历史兼容，不提前建设未来抽象。

公开 PyPI/GitHub Release 与代码合并分开；生产或公开发布依明确授权。
