# 个人研究工作台

慢慢看的日常主线是：**我的关注 → 核对变化 → 保存观察 → 连续复看**。Web 与终端使用同一份本地数据和观察记录，板块发现、用户条件筛选、对比和研究证据作为后续入口。

## 开始使用

```bash
kan web
kan tui
```

Web 默认打开“我的关注”。已有自选、持仓和未排除的人工候选自动汇集，重复代码只显示一行，并保留所属来源。空工作区点击“添加关注”输入明确代码；终端按 `a` 添加。添加只记录用户选择，不自动抓取全市场，也不预置股票组合。

首页首先读取本地缓存。需要新数据时，点击“更新关注数据”或按 TUI 帮助中的更新键；只更新当前关注池，使用已有持久任务显示成功、部分失败、中断或错误。批量数据管理仍可从独立入口操作。

## 核对事实

表格显示价格、相邻行情涨跌、30 日区间位置与复看状态。选中对象后展示 30/60/180 日区间位置、变化、行情数据日和缓存来源。“完整研究”继续查看其他已有证据。

- **行情数据日**是实际缓存最后一条可用完整日线的日期，不是打开页面的日期。
- **区间位置**由共享 `scan_stock` 计算；本期与上期在同一缓存复权序列上计算，避免直接比较不同复权基准的历史快照。
- **相邻行情变化**使用实际最新两条可用日线，界面同时保留两个日期；停牌或缓存缺行时不能称为相邻交易日。
- **位置变化**的单位是百分点，不是收益率。样本不足时保留缺失，不以零替代。
- **新鲜度**依据本地有效交易日历判断；日历不可用时明确显示时效待核对，不为了首页自动联网。
- 本地缓存只标 `local_cache` 时，表示无法从该缓存追溯到更具体的数据提供商；不能将它描述为某个上游的直接实时返回。

“已复看”与“最新行情”是不同事实。可以复看一份较旧数据，但界面仍保留其实际日期和陈旧提示。

## 写观察与复看

1. 选中对象，在“我的观察”中记录待核对的事实或问题。
2. 保存笔记，确认成功反馈。
3. 核对完当前数据后，标记已复看。
4. 下次打开仍显示笔记和最近复看；行情日、价格、区间位置或观察内容改变时，重新进入待复看。

笔记复用已有候选记录，不建立另一份独立笔记数据库。对象存在于多个候选列表时，保留各列表的原始笔记；更新只修改指定的那一份，不清空其他列表，也不更改来源运行。

复看记录保存在现有 SQLite `workspace_state`，包含实际保存时间、行情数据日、当时价格、区间位置和笔记。同一份内容重复点击不会制造重复记录。界面返回最近五次，历史存储不因界面截断而删除。没有完整行情时不能标记已复看。

## 两种界面，同一条路径

Web 在桌面上并列呈现列表和详情；窄屏中选择对象后进入详情，并可明确返回列表。搜索、待复看与有笔记过滤只整理已有对象，不根据行情自动筛选或评分。

TUI 用方向键选择、`Enter` 打开详情、`/` 搜索、`a` 添加、`n` 编辑观察、`?` 查看帮助、`Esc` 返回、`q` 退出。更新在后台执行，界面保留响应。非交互终端不会进入全屏循环；自动化继续使用原 CLI 和 JSON。

“发现与筛选”中的板块趋势、条件规则与板块复看，已有候选管理、横向对比、持仓、数据管理和设置均保留。规则命中不会自动加入长期关注；人工候选与不可变运行结果保持分离。

## 共享接口

| 操作 | 接口 |
|---|---|
| 读取关注快照 | `GET /api/v1/focus` |
| 添加明确代码 | `POST /api/v1/focus`，请求 `{ "symbol": "600519" }` |
| 更新指定笔记 | `PUT /api/v1/focus/{symbol}/note`，请求 `note` 与可选 `list_id` |
| 保存复看记录 | `POST /api/v1/focus/{symbol}/review` |
| 更新关注行情 | `POST /api/v1/jobs/market-refresh`，`scope: "focus"` |

保存复看时，两种界面都会传入当时看到的行情版本标识；期间行情已改变则提示重新读取，不将未看到的新数据算作已复看。

Python 从 `kan.api` 导入 `build_focus_snapshot`、`add_focus`、`update_focus_note` 和 `mark_focus_reviewed`。HTTP 保留现有本地会话与同源校验，严格模型由 OpenAPI 生成前端类型。这里的代码只演示 API 输入格式，不是关注建议。

## 数据与升级

继续使用原 SQLite、Parquet、自选和持仓存储；不删除或覆盖既有用户数据，不新增云账号或遥测。关注接口不复制持仓成本、股数或现金。完整备份与回滚入口见 [`workspace-migration.md`](workspace-migration.md)。

历史价格不预示未来；工具呈现事实、用户明确的条件和人工记录，不输出买卖建议、评分或预测。
