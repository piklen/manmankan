# v0.0.6.x 用户版回顾

发布日期:2026-05-30 ~ 2026-07-10

## 本版重点

- `kan web`:普通 A 股用户的默认入口,在浏览器里查看今日变化、数据新鲜度、自选、持仓和中文条件筛选。
- 今日页默认聚焦 30 / 60 / 180 日,显示当前截止日、正常应截止日、180 日高低位和上一份不同交易日快照变化。
- 自选、持仓和现金都能在 Web 内新增、修改和删除;完整十周期与等价 CLI 按需展开。
- `kan history <代码或名称>`:离线回看单只股票每日扫描快照里的位置百分位历史。
- `kan find` 扩展为用户主导筛选器:支持位置、共振、估值、资金、技术、筹码、股东等显式 filter。
- `kan find --codes` / `kan scan --codes`:外部代码池可直接接入,不必先写入自选。
- `kan find --all`:全市场截面 JSON / Markdown 取数,适合脚本和外部 AI 做下一步处理。
- `kan board rank`:行业 / 题材维度榜单,支持按资金、涨幅、位置排序。

## 使用提示

```bash
kan web
kan history 600519 --period 30
kan find --codes 600519,000858 --pos 180:lt:20 --format json
kan find --all --pe lt:20 --format json --compact
kan board rank --kind industry --by moneyflow --format json
```

`kan find --all` 以及估值 / 质量 / 资金 / 技术 / 筹码 / 股东类 filter 依赖 TuShare Pro token 或对应上游数据。未配置 token 时,自选 / 行业 / 题材 / 外部代码池的位置、共振、涨幅等 K 线类筛选仍可用。

## 已知边界

- 数据是延时日 K / 截面数据,不适合分钟级短线。
- 上游公开数据源可能限流或临时变更接口;命令会尽量给出可继续操作的错误提示。
- 工具只输出客观数据和用户指定 filter 的命中结果,不提供买卖建议、评级或目标价。
