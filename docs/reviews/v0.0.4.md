# v0.0.4.x · 散户语言全面升级 + 装机崩 hotfix + 数据时效性修复

> 📅 发布日期:2026-05-12 ~ 2026-05-16(共 6 个 patch · v0.0.4.0 → v0.0.4.8)
> 📦 PyPI:`pip install --upgrade manmankan` 即装最新
> 📄 简洁版:[CHANGELOG.md](../../CHANGELOG.md)

v0.0.4 系列总共发了 6 个 patch · 主要解决 3 件事:
1. **装机崩**(v0.0.4.4 hotfix)
2. **数据时效性核心修复**(v0.0.4.5 必升级)
3. **散户语言全面升级**(v0.0.4.7 + v0.0.4.8)

---

## ✨ 关键改动

### 启动可见反馈(v0.0.4.0 - v0.0.4.3)

`scan / low / high / info / trend / fetch / add` 命令入口加 spinner · 不再"按下回车后空屏 1 秒"。
首帧反馈从 660ms 压到 220ms。

### 装机崩 hotfix(v0.0.4.4 必升级)

v0.0.4.3 在 macOS Gatekeeper / numpy 版本错位下装机即崩(spinner 没出现就 import 异常)。v0.0.4.4 修了 numpy 版本 cap + 顶层 import 防御。

### 数据时效性核心修复(v0.0.4.5 必升级)

旧版凌晨拉数据后 `kan scan` 整天显示昨日涨停名单 · 已修(缓存新鲜度判据从 mtime 改为 K 线 date 列)。**强烈建议升级到 v0.0.4.5+**。

### Tab 补全 bug 修复(v0.0.4.6)

`kan upd<Tab>` zsh 报错修复。

### 装机门槛降低(v0.0.4.7)

- `scripts/install.sh`(mac/Linux)+ `scripts/install.ps1`(Windows)一键脚本 · 第一次用命令行的散户复制粘贴 2 步装好
- README "🌱 新手专区" 折叠块默认展开 · 含 mac / Win 各 2 步装机指南 + FAQ

**安装命令**(新手):

```bash
# mac / Linux
curl -LsSf https://raw.githubusercontent.com/piklen/manmankan/main/scripts/install.sh | bash

# Windows PowerShell
iwr -useb https://raw.githubusercontent.com/piklen/manmankan/main/scripts/install.ps1 | iex
```

### 检查缓存 spinner 进度(v0.0.4.7.1)

旧版 169 只自选股冷启动 `kan scan` 卡在 `⏳ 检查缓存...` 沉默 30 秒 · 真小白误判卡死。修复后改为 3 阶段 spinner:

```
⏳ 加载数据模块...
⏳ 加载交易日历 · 169 只自选股待检查...
⏳ 检查缓存 80/169 只 · 已发现 23 只 stale
```

### 散户语言全面升级(v0.0.4.8)

- `kan add 招商` 多匹配时列候选(`600036 招商银行; 600999 招商证券; ...`)· 不再冷冰冰报错
- `kan add` 无参 → 中文友好提示("用 kan add 600519 加自选股")
- `kan remove` / `kan info` 同款散户中文
- 错误消息加"下一步引导"(`未找到... · 试 kan list 看自选 / 用代码精确加 kan add 600519`)
- spinner 加 ✅/❌ + 失败累计(`⏳ 补数据 169 只 · ✅ 茅台` / `❌ 中铝… · 失败 3`)
- 涨跌停状态描述无预测性词(去掉"可能回落 / 可能回升"等暗示)

### 凌晨 / 晚间日期友好提示(v0.0.4.8)

`fetched_at` 当天 00:00-04:59 显示 "今晨 01:00" · 昨天 22:00-23:59 显示 "昨晚 23:50" · 散户秒懂。

### 数据源防御纵深(v0.0.4.7 - v0.0.4.8)

- `latest_trade_date()` 失败不再抛 RuntimeError · 退化 weekday 启发式 + stderr warning
- pandas 上界收紧到 < 3 防 pandas 3.0 read_parquet schema 严格化破坏
- max_workers 自适应 `min(cpu_count*2, 12)` · 8 核 Mac 首次补全 169 只时间减半
- `KAN_WORKERS` env var 让弱网用户手动降并发
- `KAN_DATA_AVAIL_OFFSET_MIN` env var 让跨时区 / WSL2 UTC / Docker 容器用户自救

### 隐私 + 安全升级(v0.0.4.8)

- `debug_log` 自动 mask `/Users/<user>` + `token=<redacted>` · 防 issue 截图 PII leak
- `install.sh` SHA256 在 release notes 公布 · 文化层防御 `curl|bash` 攻击
