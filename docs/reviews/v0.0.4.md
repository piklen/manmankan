# v0.0.4.x · 散户语言升级 + 安装修复 + 数据时效性修复

> 📅 2026-05-12 ~ 05-16(v0.0.4.0 → v0.0.4.8)· 📄 简洁版:[CHANGELOG.md](../../CHANGELOG.md)

本系列主要解决三件事:

1. **数据时效性修复(v0.0.4.5 · 强烈建议升级)** —— 凌晨拉数据后 `kan scan` 整天显示昨日涨停名单的问题已修;缓存新鲜度判据由文件 mtime 改为 K 线 date 列(对比 A 股交易日历)。
2. **安装稳定性修复(v0.0.4.4)** —— 依赖加版本上限、升级走 force-reinstall、升级后跑 import smoke test,避免安装后导入失败。
3. **散户语言升级(v0.0.4.7 + v0.0.4.8)** —— 一键安装脚本 + 新手专区;`kan add` 多匹配列候选、无参中文提示;错误消息加「下一步引导」;日期友好提示(「今晨 01:00」/「昨晚 23:50」)。

其他改动:启动可见反馈(spinner)、Tab 补全 hotfix、数据源容错纵深、`KAN_WORKERS` / `KAN_DATA_AVAIL_OFFSET_MIN` env var、用户数据文件权限收紧(0600 / 0700)。

## 升级

```bash
uv tool install --upgrade manmankan   # 或 pipx upgrade / pip install --upgrade
```
