# v0.0.5.0 · 热榜 / 题材扫描 + TuShare Pro + 5 档成交量

> 📅 2026-05-23 · 📄 简洁版:[CHANGELOG.md](../../CHANGELOG.md#0050---2026-05-23)

本版新增 4 个方向:

1. **东方财富热榜扫描** —— `--hot rank|surge` 把人气榜 / 飙升榜当临时标的来源,套用多周期位置 / 趋势分析;`--only-watchlist` 取自选交集。支持 scan / low / high / trend / fetch。
   ```bash
   kan scan --hot rank --only-watchlist
   ```
2. **TuShare Pro 可选数据源** —— `kan config set tushare-token <token>` 后顶替 baostock 作主源;不配 token 行为零变化;token 自动 mask,永不进 logs。
3. **题材位置扫描** —— `--theme=<题材名>`,9 命令支持,`kan theme list/search` 发现入口。题材分类来自同花顺口径,题材跟风风险高于行业。
   ```bash
   kan scan --theme=AI应用
   ```
4. **成交量异动 5 档对称识别** —— scan 表 / `kan info` 的量能 label 由 2 档扩为 5 档(明显放大 / 温和放大 / 量能平稳 / 温和萎缩 / 明显萎缩)。

## 已知问题

- 题材成分股数据源受上游限流 / 接口变更影响可能阶段性不可用;触发时给友好提示,可改用 `--industry`。
