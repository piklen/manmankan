## ✨ 本版新功能

### 1. 东方财富热榜扫描(`--hot rank|surge`)

把东财人气榜 / 飙升榜当作"临时自选股"标的来源 · 套用慢慢看的多周期位置 / 趋势分析。

**散户使用场景**(深夜复盘):

```bash
# 看今日散户讨论最热的标的
kan scan --hot rank

# 只看你自选里也在热榜上的(过滤噪音)
kan scan --hot rank --only-watchlist

# 飙升榜(短线技术异动)
kan scan --hot surge
```

支持命令:`scan` / `low` / `high` / `trend` / `fetch`。表格新增"榜"列(实时名次)· JSON cache 1h(减少接口压力)。

> 💡 **盘后跑反映今日散户讨论焦点**:`--only-watchlist` 帮你筛出"你的自选里也在热榜上的股" · 明天开盘前心里有数。

### 2. TuShare Pro 可选数据源

如果你有 TuShare Pro 账号 · 用 `kan config` 配置 token 即可顶替 baostock 作主数据源。**不配 token 行为完全零变化** · 现有用户无感。

```bash
# 配置 token(在 https://tushare.pro 申请)
kan config set tushare-token <你的_token>

# 查看(token 自动 mask · 只显示末 4 位)
kan config get

# 清空
kan config unset tushare-token
```

也支持环境变量 `TUSHARE_TOKEN` / `TUSHARE_ENDPOINT` 在运行时覆盖。endpoint 可填自部署镜像 / 反代(默认 `https://api.tushare.pro`)。

**安全保证**:token 自动 mask + 永不进入 logs / exceptions / debug 输出。

### 3. 题材位置扫描(`--theme=<题材名>`)

题材是行情商标签型分类(如"AI 应用 / 半导体 / 新能源车" 等)· 一只股可能在多个题材里。

```bash
# 发现题材
kan theme list                 # 列前 30 个题材(拼音序)
kan theme list --all           # 列全部 ~391 个 + 散户超载警告
kan theme search AI            # 模糊搜题材

# 看题材位置
kan scan --theme=AI应用        # 扫描 AI 应用题材所有成分股位置
kan low --theme=半导体 60      # 半导体题材里 60 日低点
kan info 600519                # 看个股属于哪些题材

# 批量加自选(慎用 · 二次确认)
kan add --theme=AI应用         # 把 AI 应用所有成分股加自选
```

**支持矩阵**:9 个命令支持 `--theme`:
- 7 个只读命令(`scan / low / high / trend / info / list / fetch`),其中 5 个支持 `--only-watchlist` 取自选交集
- 2 个破坏性命令(`add / remove`),必经二次确认,`--yes` 跳过(慎用)

**重要提示**(disclaimer 比 `--industry` 更强一档):
- 题材分类各家口径不同(本工具用同花顺)
- 题材跟风风险高于行业
- 题材是标签 · 一股归多个

**数据源**:同花顺 catalog/成分股 + 东方财富 K 线/反查 · 零 token 零配置。上游限流时自动 5 分钟冷却 · 不重复打挂数据源。

### 4. 成交量异动 5 档对称识别

从 v0.0.5.0 起 · `kan scan` 表 / `kan info` 详情里的成交量 label 从 2 档扩为 **5 档对称**:

| 倍数(今日成交 / 5 日均量) | label |
|---|---|
| ≥ 2.0x | 明显放大 |
| 1.5 - 2.0x | 温和放大 |
| 0.67 - 1.5x | 量能平稳 |
| 0.5 - 0.67x | 温和萎缩 |
| < 0.5x | 明显萎缩 |

**修复**:旧版"涨停日 1.73 倍误标量能平稳" → 新版正确标"温和放大"。

边界对数对称(2.0×0.5=1.0 · 1.5×0.67≈1.0)· 阈值表也加进 `kan info --help`。

## ⚠️ 已知问题

- **题材成分股数据源动态不稳定**:同花顺 / 东方财富接口受上游限流 / 反爬影响 · 可能阶段性不可用。触发时给友好提示"题材数据源暂不可用 · 行业扫描可用(`--industry`)"。已有 5 分钟冷却防雪崩 + 24h cache 兜底。
- **Apple Silicon arm64 + 题材功能**:某些题材数据路径在 arm64 上 dylib 缺失会有 debug log noise(题材扫描已绕开主路径 · 不影响核心功能)。M1+ Mac 用户题材出错时改用 `--industry` 替代。
